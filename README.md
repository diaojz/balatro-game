# Balatro (小丑牌) 游戏 - 第一节课完成版

> 基于 Steam 平台《Balatro》的简化版实现

## 项目概述

这是一个单机版的 Balatro 扑克牌游戏，使用 Vue 3 + Vite + Tailwind CSS 开发。

## 已完成功能（第一节课）

### ✅ 核心游戏循环
- 扑克牌型识别（9 种牌型）
- 计分系统（筹码 × 倍率）
- 盲注系统（3 个盲注）
- 手数限制（4 手）
- 游戏胜负判定

## 游戏玩法

1. **选牌**：点击手牌选择 5 张牌（选中的牌会高亮并上移）
2. **出牌**：点击"出牌"按钮
3. **查看结果**：系统自动识别牌型并计算得分
4. **通过盲注**：累计得分达到目标分数即可通过当前盲注
5. **游戏胜利**：通过所有 3 个盲注即可获胜

## 计分公式

```
最终得分 = (基础筹码 + 牌点数总和) × (基础倍率 + 小丑加成)
```

**牌点数**：
- 2-10：对应点数
- J/Q/K：10 点
- A：11 点

**示例**：
- 打出一对 K（基础：10 筹码 × 2 倍率）
- 牌点数：10 + 10 + 5 + 3 + 2 = 30
- 最终得分：(10 + 30) × 2 = 80 分

### 常见问题

**Q: 为什么选中的牌会上移？**  
A: 使用了 Tailwind 的 `-translate-y-4` 类，配合 `transition-all` 实现平滑动画。

**Q: 如何识别顺子？**  
A: 将牌排序后，检查相邻牌的点数是否连续。特殊处理 A-2-3-4-5 的情况。

**Q: 计分公式为什么是乘法？**  
A: 这是 Balatro 的核心机制，通过乘法实现"得分爆炸"的快感。
