## 游戏玩法

### 基础操作
1. **选牌**：点击手牌选择牌（选中的牌会高亮并上移）
2. **出牌**：选择 5 张牌后点击"出牌"按钮
3. **弃牌**：选择任意张数的牌后点击"弃牌"按钮（每回合 3 次机会）
4. **查看结果**：系统自动识别牌型并计算得分
5. **通过盲注**：累计得分达到目标分数即可通过当前盲注

### 商店系统
- 通过盲注后自动打开商店
- 可以购买 3 个随机小丑牌
- 可以出售已拥有的小丑牌（售价为购买价的一半）
- 最多持有 5 个小丑牌

### 小丑牌效果
- 小丑牌在出牌时自动生效
- 不同小丑牌可以叠加效果
- 合理搭配小丑牌可以获得更高分数

## 计分公式

```
最终得分 = (基础筹码 + 牌点数总和) × (基础倍率 + 小丑加成)
```

**牌点数**：
- 2-10：对应点数
- J/Q/K：10 点
- A：11 点

**示例**：
- 打出一对 K（基础：10 筹码 × 2 倍率）
- 牌点数：10 + 10 + 5 + 3 + 2 = 30
- 最终得分：(10 + 30) × 2 = 80 分

### 常见问题

**Q: 为什么选中的牌会上移？**  
A: 使用了 Tailwind 的 `-translate-y-4` 类，配合 `transition-all` 实现平滑动画。

**Q: 如何识别顺子？**  
A: 将牌排序后，检查相邻牌的点数是否连续。特殊处理 A-2-3-4-5 的情况。

**Q: 计分公式为什么是乘法？**  
A: 这是 Balatro 的核心机制，通过乘法实现"得分爆炸"的快感。
